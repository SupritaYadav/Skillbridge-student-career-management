# SkillBridge Frontend

Complete React/Vite UI for the SkillBridge Student Career & Skill Management System.

## Run
1. Open terminal inside this `frontend` folder.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the Vite URL, normally http://localhost:5173.

The Student and Skills pages connect to the existing Spring Boot backend at `http://localhost:8080/api`.
- `/api/students`
- `/api/skills`

Projects, certifications and learning goals currently use browser localStorage so the UI works immediately. They can be connected to Spring Boot later.
